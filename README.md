# melamina-pro-b

Landing del A/B de melamina, encuadre **B**. Construida con el molde de
`edicion-pro.com` (CapCut): misma estructura, misma mecanica de video de YouTube,
paleta grafito + un solo acento naranja de herramienta.

- `index.html`    — encuadre base
- `v2/index.html` — mismo producto y mismo precio, con los gatillos de venta apilados
  (anclaje de precio, especificidad, prueba de entrega, objeciones, bonos apilados, FAQ, CTA repetido)

Todo numero de la pagina se **deriva** de la entrega viva de UTEC
(`obras/landings_melamina_ab/contar_inventario.py`), no se escribe a mano.

**Checkout pendiente**: el boton no cobra. Se activa poniendo los 4 payment links
en `LK` y `BLOQUEADO = false`. El pixel va en `PIXEL_ID = null` hasta que Esteban diga cual.
